# Quarterly database review, Q2 2026

- Largest tables: `order_items` (3.9 M rows), `payments` (2.3 M), `orders` (1.2 M).
- All top-10 statements by total time use an index. The customer order list uses
  `idx_orders_customer_created (cust_id, created_at)` and takes 0.4 ms on average.
- `customers` lookups by email use `lower(email) LIKE '%...%'` in the admin search: sequential scan, 1.3 s.
  Acceptable for an internal tool; a trigram index would fix it.
- No unused indexes found.
- Action for Q3: the planned rename of `orders.cust_id` needs a table rebuild on the current engine version;
  schedule it outside business hours and verify indexes afterwards.
