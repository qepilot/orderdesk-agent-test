# test_invoice_issued_today fails only in the nightly run

## Symptom
`tests/test_invoicing.py::test_invoice_issued_today` passes on every push during the day and fails in the
scheduled run at 00:30.

## Analysis
The test compares the date part of the invoice timestamp, which the application writes in UTC, with
`date.today()`, which uses the timezone of the machine. The CI runner is set to Europe/Berlin. Between midnight
and 01:00 or 02:00 local time the UTC date is still the previous day, so the two dates differ.

## Status
Known flaky test, not fixed. Proposed fix: compare with the current UTC date, or pass a fixed timestamp to
`issue_invoice` in the test.

## Lesson
A test that reads the clock or the timezone of the machine is a test of the machine. Inject the time.
